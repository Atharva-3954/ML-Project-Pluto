# Titanic Survival Prediction using Machine Learning

## Project Overview

In this project, I used the Titanic dataset to predict whether a passenger survived or not. The goal was to preprocess the data, train different machine learning models, and compare their performance.

## Dataset Information

**Dataset:** Titanic Survival Prediction Dataset

**Source:** Kaggle

**Files Used:**

* `train.csv`
* `test.csv`
* `gender_submission.csv`

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## Analysis Performed

* Data Preprocessing
* Missing Value Handling
* Feature Selection
* Model Training
* Model Evaluation
* Model Comparison

## Models Used

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Random Forest Classifier

## Evaluation Metrics

* Accuracy Score
* Confusion Matrix
* Classification Report

## Key Findings

* Random Forest performed the best among all models.
* Passenger class and gender had a strong impact on survival.
* Data preprocessing improved model performance.
* Different models produced different accuracy scores.
